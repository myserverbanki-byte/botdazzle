# Что делать если база данных не работает на Vercel

## Быстрая диагностика

### 1. Откройте страницу отладки
```
https://ваш-домен.vercel.app/debug
```

Вы должны увидеть:
- ✓ Переменные найдены
- VITE_SUPABASE_URL: "https://xxxxx.supabase..."
- VITE_SUPABASE_ANON_KEY: "eyJ..."

### 2. Если переменные НЕ найдены:

**Проблема:** Vercel не видит переменные окружения

**Решение:**

1. Откройте [Vercel Dashboard](https://vercel.com/dashboard)
2. Выберите ваш проект
3. **Settings → Environment Variables**
4. Добавьте две переменные:
   - `VITE_SUPABASE_URL` (ваш URL из Supabase)
   - `VITE_SUPABASE_ANON_KEY` (ваш ключ из Supabase)
5. ⚠️ **ВАЖНО:** Выберите все окружения (Production + Preview + Development)
6. Сохраните

7. **Redeploy с очисткой кэша:**
   - Deployments → последний деплой → ... → Redeploy
   - ✅ Отметьте "Clear cache and rebuild"
   - Нажмите Redeploy

8. Дождитесь завершения деплоя
9. Снова откройте `/debug` - переменные должны появиться

### 3. Где взять VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY?

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Выберите проект (или создайте новый)
3. **Settings → API**
4. Скопируйте:
   - **Project URL** → это ваш `VITE_SUPABASE_URL`
   - **anon public** key → это ваш `VITE_SUPABASE_ANON_KEY`

### 4. Создайте таблицу в Supabase

Если таблица еще не создана:

1. В Supabase: **SQL Editor**
2. Вставьте и выполните код из [QUICK_START.md](./QUICK_START.md) (раздел "Создайте таблицу")

## Типичные ошибки

### Ошибка: "Invalid API key"
**Причина:** Неправильный ключ

**Решение:** 
- Убедитесь, что копируете **anon public** key (НЕ service_role!)
- Ключ должен начинаться с `eyJ`

### Ошибка: "Could not connect to database"
**Причина:** Неправильный URL

**Решение:**
- URL должен быть вида `https://xxxxx.supabase.co`
- Проверьте в Supabase Dashboard что проект активен

### После добавления переменных ничего не изменилось
**Причина:** Vercel использует старую сборку

**Решение:**
- Обязательно сделайте Redeploy с "Clear cache and rebuild"
- Без очистки кэша переменные не применятся

## Альтернатива: Работа без базы данных

Если не хотите настраивать Supabase:

1. НЕ добавляйте переменные окружения в Vercel
2. Приложение автоматически будет использовать localStorage
3. Данные сохранятся только в браузере пользователя
4. При очистке кэша браузера данные удалятся

Это подходит для:
- Демо/прототипов
- Локальной разработки
- Тестирования

НЕ подходит для:
- Production с реальными пользователями
- Если нужна синхронизация между устройствами

## Нужна помощь?

1. Проверьте консоль браузера (F12 → Console) на ошибки
2. Посмотрите логи деплоя в Vercel (Deployments → Build Logs)
3. Убедитесь, что все шаги выполнены в правильном порядке
